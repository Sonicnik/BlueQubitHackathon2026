# DuQuHack: BlueQubit Duke challenge

Goal: maximize corr² x points on 7 circuits (S1 to S3 samples, G1 to G4 hidden) by estimating echo expectations with BlueQubit simulators, ending Oct 25, 2026, 11:30 a.m. ET. Build and run a local autoresearch loop.

## Working with the user

The user's Mac runs this loop. They submit on the platform. Stop and write `QUESTIONS.md` when something differs from what the docs expect, or when a decision is the user's (spend beyond the cap, plan changes, rule ambiguity), and keep doing safe free work meanwhile.
